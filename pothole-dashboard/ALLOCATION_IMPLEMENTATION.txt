========================================
KEY DESIGN DECISIONS
========================================

1. Recency Weights:
   - 1 day: 1.20x (urgent)
   - 1-3 days: 1.00x (baseline)
   - 3-7 days: 0.85x (aging)
   - >7 days: 0.70x (old)

2. Cluster Boost:
   - +8% per neighbor within 750m
   - Capped at 5 neighbors (40% max boost)
   - Encourages repair efficiency

3. Score Formula:
   score = severity  confidence  recency  cluster

4. Missing Data:
   - severity/confidence default to 0.5
   - Flags added to breakdown
   - Invalid dates return neutral weight (1.0)

5. Scaling Considerations:
   - Current: O(n) cluster calculation
   - Suitable for <1000 reports
   - For production: use spatial indexing
